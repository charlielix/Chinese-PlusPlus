# Chinese-Plus-Plus

用中文写 C++。一套中文宏库 + 中文数字双向转换，让变量、关键字、容器、算法乃至数字本身都可以用中文书写，且不带来任何运行期开销。

```cpp
#include "chinese.hpp"

开辟命名空间 std;

整数 主函数() {
    整数 甲 = 七, 乙 = 三;
    输出 << "甲 加 乙 = " << (甲 加 乙) << 换行;   // 10
    返回 零;
}
```

## 特性

- **252 个中文宏**：常数、类型、控制流、类与泛型、中缀运算符、STL、算法、数学函数
- **中缀运算符**：`甲 加 乙 乘 二`、`甲 取余 乙 相等 一`、`甲 大于 乙 逻辑与 ...`
- **面向对象与泛型**：`类 狗 继承 动物`、`模板 <类型名 类型>`、`虚 ... 覆盖`、`纯虚`
- **中文数字双向**
  - `转中文数字(2026)` → `"二千零二十六"`，支持负数与到 `亿亿`（10^16）的大数
  - `中文数("二千零二十六")` → `2026`，`consteval` **强制编译期求值**
- **零运行期开销**：宏是纯文本映射，数字在编译期变成立即数（`-O0` 下同样成立）
- **自带自测**：`TESTING/main.cpp` 覆盖运算符、控制流、继承多态、模板、STL、算法、字符串、中文数字与编译期断言

## 环境要求

- C++20 及以上（推荐 C++23，`CMakeLists.txt` 已设为 23）
  - C++17 亦可编译，但 `consteval` 会自动退化为 `constexpr`（仍可用于常量表达式，只是不强制）
- GCC / Clang 均可，需支持 UTF-8 标识符（GCC 默认开启 `-fextended-identifiers`）
- 源文件必须保存为 **UTF-8**


## 快速开始

一条命令（自动挑选 Homebrew 装的最高版本 `g++-NN`，不依赖 shell alias）：

```bash
./run.sh
```

可用环境变量覆盖默认行为：

```bash
CXX=clang++ ./run.sh            # 换编译器
STD=c++20   ./run.sh            # 换语言标准（默认 c++23）
OPT="-O0 -g" ./run.sh           # 换编译选项（默认 -O2）
./run.sh 程序参数               # 参数会传给程序
```

手动编译：

```bash
g++ -std=c++23 -Iinclude TESTING/main.cpp -o 中文示例
./中文示例
```

或用 CMake：

```bash
cmake -S . -B build
cmake --build build
./build/Chinese_PlusPlus_Test
```

## 完整示例

```cpp
#include "chinese.hpp"

开辟命名空间 std;

类 动物 {
公有:
    字符串 名字;

    显式 动物(字符串 新名字) : 名字(移动(新名字)) {}
    虚 ~动物() = 默认;

    虚 字符串 叫声() 常量 { 返回 "……"; }
};

类 狗 继承 动物 {
公有:
    显式 狗(字符串 新名字) : 动物(移动(新名字)) {}

    字符串 叫声() 常量 覆盖 { 返回 "汪汪"; }
};

整数 主函数() {
    整数 甲 = 七, 乙 = 三;
    输出 << "甲 加 乙 = " << (甲 加 乙) << 换行;

    动态数组<整数> 数列 = {五, 三, 九, 一, 三};
    排序(起始迭代器(数列), 结束迭代器(数列));
    数列.擦除(去重(起始迭代器(数列), 结束迭代器(数列)), 结束迭代器(数列));

    计数循环 (整数 值 : 数列) 输出 << 值 << " ";
    输出 << 换行;
    输出 << "累加和：" << 累加和(起始迭代器(数列), 结束迭代器(数列), 零) << 换行;

    狗 旺财("旺财");
    输出 << 旺财.名字 << " 说：" << 旺财.叫声() << 换行;

    输出 << "人数：" << 转中文数字(2026) << 换行;

    常量表达式 整数 幸运数 = 中文数("四十二");
    输出 << "幸运数：" << 幸运数 << 换行;

    返回 零;
}
```

输出：

```
甲 加 乙 = 10
1 3 5 9
累加和：18
旺财 说：汪汪
人数：二千零二十六
幸运数：42
```

## 中文数字

### 整数 → 中文

```cpp
输出 << 转中文数字(零);            // 零
输出 << 转中文数字(15);            // 十五
输出 << 转中文数字(105);           // 一百零五
输出 << 转中文数字(1010);          // 一千零一十
输出 << 转中文数字(10001);         // 一万零一
输出 << 转中文数字(100000);        // 十万
输出 << 转中文数字(-100000000);    // 负一亿
```

大数单位：`万`(10^4)、`亿`(10^8)、`万亿`(10^12)、`亿亿`(10^16)。

### 编译期版本

```cpp
常量表达式 中文数字文本 文本 = 转中文数字常量(2026);
静态断言(文本.视图() == "二千零二十六");
静态断言(转中文数字常量(105) == "一百零五");
```

`中文数字文本` 是固定 256 字节缓冲的常量类型，零堆分配。

### 中文 → 整数（强制编译期）

```cpp
静态断言(中文数("一百二十三") 相等 123);
静态断言(中文数("一亿二千万") 相等 120000000);
静态断言(中文数("负三") 相等 -3);
静态断言(中文数("一二三") 相等 123);          // 逐位连写

静态断言(中文数(转中文数字常量(10001).视图()) 相等 10001);   // 往返一致
```

- 支持 `〇零一二三四五六七八九`、大写 `壹贰叁肆伍陆柒捌玖`、`两`
- 支持 `十 百 千 万 亿` 及复合单位 `万亿`、`亿亿`，`负`，空格与逗号分隔
- `中文数` 默认返回 `整数`，超出 `int` 范围会**编译期报错**；大数写 `中文数<长整数>("...")`

## 编译期求值与性能

`consteval` 是语言级保证，与是否开启 `-O2` 无关：

```cpp
常量表达式 整数 人数 = 中文数("一千零一");            // 单个常量
常量表达式 整数 权重[四] = {                            // 常量表
    中文数("一千"), 中文数("一百"), 中文数("十"), 中文数("一")};

模板 <整数 元素数>
结构体 固定缓冲 { 整数 数值[元素数]; };
固定缓冲<中文数("十六")> 缓冲;                          // 模板参数
```

验证方式（`-O0` 下目标文件里不应出现解析/分配符号）：

```bash
clang++ -std=c++23 -O0 -Iinclude -c 示例.cpp -o 示例.o
nm -uC 示例.o | grep -E 'operator new|中文'
```

反过来，运行期才知道的值不要走中文解析或格式化：`转中文数字` 返回 `std::string`，每次调用都会构造对象（实测 `-O2` 下仍有 `operator new`）。只做输出时可改用零分配写法：

```cpp
输出 << 转中文数字常量(人数).视图();    // 栈上缓冲，无堆分配
```

`视图()` 指向对象内部缓冲，**仅在同一个完整表达式内安全**；需要跨语句保存时先落地对象：

```cpp
常量表达式 中文数字文本 文本 = 转中文数字常量(2026);
输出 << 文本.视图();
```

## 命名冲突须知

宏是文本替换，会命中同名的标识符，因此下列词**不要**用作变量名、函数名或模板参数名：

`长度`(sizeof)、`大小`(size)、`数据`(data)、`容量`(capacity)、`追加`(append)、`成员`(.)、`绝对值`(std::abs)、`默认`(default)、`空`(void)、`类`(class)、`此`(this)、`输出`(std::cout)、`输入`(std::cin)

安全替代：`元素数`、`数值`、`字节数`、`文字`、`内容` 等。

## 已知限制

- 宏不参与作用域、重载与类型检查，只能做文本映射
- `+=`、`-=`、`->`、`::`、`?:` 等复合记号仍需原样书写（中文运算符只对应单记号）
- 中文标识符依赖 UTF-8 源文件与较新编译器；MSVC 建议加 `/utf-8`
- `转字符串` 已被占用（映射到 `std::to_string`），自定义函数请避开该名
